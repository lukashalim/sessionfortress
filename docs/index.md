# Privacy policy — Session Fortress

Local-first. Sessions stay on this device.

- We store tab titles, URLs, pin state, and Tab Group metadata so we can restore your sessions.
- We do not read page content.
- We do not sell data and we do not use it for ads.
- We make no network requests in v1. No analytics, no crash reporters, no remote fonts.
- A backup folder is used only after you pick it with a user gesture. We store the folder name for display, never an absolute OS path.
- Export and delete are local.
- Chrome Web Store privacy form: we handle web-history-like data (open tab titles/URLs) solely to provide the feature.
